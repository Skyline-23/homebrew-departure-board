책상 위에, 작은 공항.

세계 40개 공항의 출발 안내판을 배경화면과 화면 보호기로. 익숙한 항공편 글자와 색, 도시의 현지 시간이 화면 위에서 움직입니다.

세 가지 사용 방식

움직이는 배경화면, 정지 배경화면, 전체 화면 화면 보호기. 원하는 방식으로 사용할 수 있습니다.

02

40개 공항의 개성

공항마다 다른 안내판 디자인과 언어, 시간대를 담았습니다. 페이지와 공동운항 편명이 차례로 전환됩니다.

03

여러 화면에서도

모니터마다 해상도와 배율에 맞춰 그립니다. 글자 크기, 행 수와 여백을 조절해 작업 환경에 맞추세요.

설정은 간단하게.

공항, 언어, 밝기, 글자 크기, 움직임과 갱신 주기를 한곳에서. 미리 보기를 보며 내 화면에 맞게 조절하세요.

알아두면 좋은 것

실제 항공편도 볼 수 있나요?

네. 본인의 AeroDataBox RapidAPI 키를 설정하면 실시간 항공편을 조회합니다. 제공사의 별도 이용 요금제가 필요하며, 샘플 데이터는 키 없이 바로 사용할 수 있습니다.

API 요청은 언제 발생하나요?

설정한 주기에 따라 항공편을 조회하고 캐시를 공유합니다. 언어 전환, 페이지 넘김, 공동운항 편명 전환은 새 요청을 만들지 않습니다. 제공사 오류가 발생하면 서버의 재시도 안내에 따라 기다립니다.

화면이 잘리거나 글자가 너무 작다면?

화면 전체에 맞춰 그린 뒤 설정의 크기와 행 수를 조절할 수 있습니다. 서로 다른 배율의 모니터에서도 각각 맞춰 표시합니다. 설치 설명서에 확인 순서를 담았습니다.

인터넷 없이 사용할 수 있나요?

샘플 데이터와 저장한 정지 배경화면은 인터넷 없이 사용할 수 있습니다. 설치 설명서와 사진도 앱에 포함되어 있습니다. 새로운 실제 항공편 조회에는 인터넷이 필요합니다.
