# Security

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Skyline-23/homebrew-departure-board/security/advisories/new).
Include the affected version, reproduction steps and expected impact. Do not
post vulnerability details or credentials in a public issue.

Ordinary bugs belong in the public issue tracker. Remove API keys, authorization
headers, Keychain contents and personal paths from any attached logs.

Use the latest release for fixes. The app stores each user's API key in macOS
Keychain; maintainers do not supply a shared key or need your key to review a report.
