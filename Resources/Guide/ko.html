Departure Board 설치와 사용 설명서

공항 전광판을 움직이는 배경화면, 화면 보호기, 미리보기 창으로 사용하는 앱입니다. 이 설명서는 macOS와 Windows의 설치부터 설정, 여러 모니터, 업데이트와 문제 해결까지 안내합니다.

처음에는 API 키 없이 Sample schedule로 화면을 확인하세요. 실제 항공편이 필요할 때만 본인의 AeroDataBox 구독과 API 키를 연결하면 됩니다. 샘플 시간표는 실제 운항 정보가 아닙니다.

1. 내 컴퓨터에 맞는 파일 고르기

컴퓨터받을 파일지원 범위
Mac — Apple Silicon 또는 IntelDepartureBoard-버전-universal.zip 또는 Homebrew caskmacOS 12 이상. 배포 ZIP은 Developer ID 서명과 Apple 공증 적용
Windows — Intel 또는 AMD CPUDepartureBoard-win-x64.zipWindows 11. 서명 없는 프리뷰
Windows — Snapdragon 등 ARM CPUDepartureBoard-win-arm64.zipWindows 11 ARM64. 서명 없는 프리뷰

최신 파일은 공식 릴리스 페이지의 Assets에서 받습니다. Windows의 설정 → 시스템 → 정보 → 시스템 종류에서 x64 또는 ARM 기반 프로세서인지 확인할 수 있습니다. Windows ZIP에는 .NET 런타임이 포함되어 있어 별도로 설치하지 않아도 됩니다.

압축 안의 Install Guide.html을 열면 이 설명서가 브라우저에 표시됩니다. 설치 후에도 앱의 Install & user guide 버튼으로 다시 열 수 있습니다. 사진과 설명은 로컬 파일이므로 인터넷이 없어도 읽을 수 있습니다. 외부 사이트 링크와 실시간 항공편 조회에는 인터넷이 필요합니다.

2. macOS에 설치하기

Homebrew로 설치

  1. 터미널을 엽니다. Homebrew가 없다면 brew.sh의 공식 설치 안내를 먼저 따릅니다.
  2. 아래 명령을 순서대로 실행합니다.
brew tap Skyline-23/departure-board
brew install --cask skyline-23/departure-board/departure-board
open -a "Departure Board"
  1. Departure Board Settings가 열리는지 확인합니다. 앱은 메뉴 막대에서 실행되므로 Dock에 아이콘이 없어도 정상입니다.
  2. 아래의 ‘첫 화면 설정’ 순서대로 샘플 화면부터 확인합니다.

Homebrew는 앱을 /Applications에 설치하고 화면 보호기를 등록합니다. 회사에서 Homebrew 사용을 제한한다면 관리자 정책을 먼저 확인하세요.

ZIP으로 직접 설치

  1. 공식 릴리스에서 universal.zip을 받고 Finder에서 압축을 풉니다.
  2. Departure Board.app을 응용 프로그램 폴더로 옮깁니다.
  3. Departure Board.saver를 더블클릭하고 macOS의 화면 보호기 설치 안내를 따릅니다. 사용자 계정에 설치할 수 있습니다.
  4. 응용 프로그램 폴더의 Departure Board를 엽니다. 앱과 화면 보호기는 같은 버전으로 함께 업데이트하세요.

3. Windows에 설치하기

  1. CPU에 맞는 ZIP을 다운로드합니다. 다운로드한 ZIP을 바로 탐색하면서 실행하지 말고, 우클릭 → 모두 압축 풀기를 먼저 선택합니다.
  2. 풀린 폴더에서 Install Guide.html로 안내를 확인하고 Install.cmd를 더블클릭합니다.
  3. 설치가 완료되면 Departure Board Settings가 열리는지 확인합니다. 이후에는 시작 메뉴에서 Departure Board를 검색해 실행합니다.
  4. 작업 표시줄의 숨겨진 아이콘 영역에 비행기 아이콘이 있는지 확인합니다. 설정창을 닫아도 앱은 이 영역에서 계속 실행됩니다.

설치는 현재 사용자에게 적용되며 관리자 권한이 필요하지 않습니다. 기본 위치는 %LOCALAPPDATA%\Programs\DepartureBoard입니다. 시작 메뉴 바로가기를 만들고 Departure Board를 화면 보호기로 선택하지만, 유휴 대기 시간과 잠금 옵션은 Windows 설정에서 직접 정합니다.

Windows 버전은 서명 없는 프리뷰입니다. 알 수 없는 게시자 경고가 보일 수 있습니다. 공식 릴리스에서 받은 파일인지와 SHA-256을 먼저 확인하세요. 조직 정책으로 실행이 막히면 보안 기능을 끄지 말고 관리자에게 문의하세요.

다운로드 무결성 확인

ZIP과 이름이 같은 .zip.sha256 파일도 받습니다. PowerShell에서 다음 명령을 실행한 뒤 나온 해시를 .sha256 파일의 첫 값과 비교합니다. ARM64 파일은 명령의 파일명을 바꾸면 됩니다.

Get-FileHash "$env:USERPROFILE\Downloads\DepartureBoard-win-x64.zip" -Algorithm SHA256

4. 첫 화면 설정

macOS 설정창. 공항과 표시 방식, 배경화면, 데이터 연결을 한곳에서 설정합니다. 사진은 샘플 시간표를 사용합니다.

Windows 설정창. macOS와 같은 표시 옵션을 제공하며 아래 버튼에서 미리보기와 화면 보호기를 선택합니다.

  1. Airport에서 보고 싶은 공항을 선택합니다. 예: Seoul Incheon (ICN), Tokyo Haneda (HND), London Heathrow (LHR).
  2. Timetable source → Sample schedule · visual preview only를 선택합니다. 키 없이 화면과 레이아웃을 확인하는 모드입니다.
  3. Language / Board language에서 영어, 현지어 또는 두 언어 번갈아 표시를 고릅니다.
  4. Apply를 누릅니다. Windows에서는 Preview, Mac에서는 메뉴 막대의 Show Board로 전광판을 확인합니다.
  5. 표시가 마음에 들면 배경화면 또는 화면 보호기로 설정합니다. 실제 항공편 연결은 다음 항목을 참고하세요.

5. 배경화면과 화면 보호기

움직이는 배경화면

Live wallpaper(Mac) 또는 Live desktop wallpaper(Windows)를 켜고 Apply를 누릅니다. 전광판이 바탕화면 아이콘 뒤에서 갱신됩니다. 앱이 실행 중이어야 계속 움직이며, 완전히 종료하면 움직이는 전광판도 사라집니다.

Show on all Spaces / Show on all desktops는 여러 가상 데스크톱에 표시할지를 정합니다. 여러 물리 모니터를 하나의 가로로 긴 전광판으로 합치는 옵션은 아닙니다. 각 모니터에는 별도의 전광판이 표시됩니다.

로그인할 때도 계속 쓰려면 Launch in background at login / sign-in을 켭니다. 배경화면이 필요 없으면 Live wallpaper를 끄고 Apply를 누르세요.

Wallpaper Engine 등 다른 배경화면 앱이 실행 중이면 Departure Board가 가려질 수 있습니다. 배경화면을 관리하는 앱 하나만 재생하도록 설정한 뒤 확인하세요.

정지 배경화면

Set as Wallpaper는 현재 전광판을 정지 이미지로 저장해 시스템 배경화면으로 지정합니다. 이 이미지는 앱을 종료해도 남지만, 이후 시간과 항공편은 갱신되지 않습니다. 움직이는 화면이 목적이라면 Live wallpaper를 사용하세요.

전광판의 머리글과 마지막 줄은 메뉴 막대·Dock·작업 표시줄의 사용 영역을 피해 배치됩니다. 배경화면의 바깥 여백은 이를 위한 공간입니다. Windows의 정지 이미지는 생성 당시 모니터 배치에 맞춰지므로 모니터 구성이나 해상도를 바꾼 뒤에는 다시 Set as Wallpaper를 누릅니다.

화면 보호기

macOS: 앱 메뉴의 Screen Saver Settings를 열거나 시스템 설정에서 ‘화면 보호기’를 검색합니다. Departure Board를 선택하고 시스템의 미리보기로 확인합니다. 시작까지의 대기 시간과 잠금 설정은 macOS에서 정합니다.

Windows: 앱에서 Set as screen saver를 누릅니다. Windows 시작 메뉴에서 ‘화면 보호기 변경’을 검색해 DepartureBoard가 선택되어 있는지 확인하고 미리 보기를 누릅니다. 대기 시간과 다시 시작할 때 로그온 화면 표시를 원하는 값으로 정한 뒤 적용합니다.

화면 보호기는 전체 화면을 사용합니다. 키를 누르거나 마우스를 움직이면 종료됩니다. 설정창의 Preview는 일반 창이며, Windows 시스템의 화면 보호기 Preview와 다릅니다.

샘플 시간표 예시. 페이지·언어·공동운항 편명이 순환하므로 한 화면에 모든 항공편이 동시에 보이지 않을 수 있습니다.

6. 실제 항공편 연결

  1. RapidAPI에 로그인합니다.
  2. AeroDataBox 요금제를 확인하고 필요한 구독을 활성화합니다. RapidAPI 계정만 만드는 것으로는 API 구독이 완료되지 않습니다.
  3. RapidAPI의 Developer Dashboard에서 앱의 X-RapidAPI-Key를 복사합니다.
  4. 앱에서 Timetable source → Live flight data를 고르고 API key에 키를 넣은 뒤 Apply를 누릅니다.
  5. Last update가 갱신되고 실제 항공편이 나타나는지 확인합니다. 데이터가 없다는 표시와 키·구독 오류 표시는 의미가 다릅니다.

키는 macOS Keychain 또는 Windows Credential Manager에 저장됩니다. 프로젝트에 전송하거나 공유하지 않습니다. 저장된 키가 점으로 표시되어 있으면 다시 붙여 넣을 필요가 없습니다. 스크린샷이나 오류 제보에 키를 포함하지 마세요.

Data refresh / Refresh flights는 API 조회 주기입니다. 새로 설치하면 기본값은 5분이며, 기존에 고른 주기는 유지됩니다. 자주 조회할수록 요금제 할당량을 더 빨리 사용할 수 있습니다. 언어·페이지·공동운항 편명 전환에는 새 API 요청이 필요하지 않습니다. 앱과 화면 보호기는 캐시와 요청 잠금을 공유합니다. 제공사가 오류를 반환하면 공항을 바꿔도 같은 실패 요청을 반복하지 않고 재시도 대기를 공유합니다. 미리 보기·설정·움직이는 배경화면 없이 트레이나 메뉴 막대에만 있는 앱은 항공편을 계속 조회하지 않습니다. 제공사의 실제 요금과 한도를 확인하고 설정하세요.

8. 여러 모니터와 서로 다른 배율

Windows의 설정 → 시스템 → 디스플레이에서 각 화면을 선택해 해상도와 배율을 확인합니다. 예를 들어 4K 화면 150%와 FHD 화면 100%처럼 서로 다른 배율을 쓰는 구성이 ‘혼합 DPI’입니다. 앱의 Board scale과 Windows의 화면 배율은 서로 다른 설정입니다.

  1. Windows의 표시 모드를 확장으로 설정합니다. 복제 모드는 같은 화면을 반복하므로 독립된 두 화면 검증이 아닙니다.
  2. 식별을 눌러 화면 번호를 확인하고, 실제 위치에 맞게 왼쪽·오른쪽·위아래로 배치합니다. 주 모니터 왼쪽이나 위쪽 화면도 사용할 수 있습니다.
  3. 각 화면에서 Live wallpaper의 머리글, 마지막 행, 날짜·시간이 잘리지 않는지 확인합니다. 작업 표시줄을 옮긴 뒤에도 확인합니다.
  4. Windows 화면 보호기 미리보기를 시작해 모든 화면이 채워지고 마우스 입력으로 정상 종료되는지 확인합니다.
  5. 앱의 Preview 창을 화면 사이로 옮겨 글자가 흐려지거나 내용이 창 밖으로 밀려나지 않는지 확인합니다.
  6. 모니터를 연결·분리하거나 해상도를 바꾼 뒤 정지 배경화면을 쓰고 있다면 다시 적용합니다.

가상 디스플레이로 확인한 결과와 물리 모니터에서 확인한 결과는 검증 기록에 구분해 기록합니다. 원격 데스크톱 한 화면의 해상도를 키우는 것만으로는 실제 다중 모니터나 혼합 DPI를 검증한 것이 아닙니다.

2560×1440, 200% 배율의 가상 화면에서 캡처했습니다. 1920×1080, 100% 화면과 동시에 검증했으며, 물리 모니터 촬영 사진은 아닙니다.

9. 업데이트와 제거

Mac / Homebrew: 아래 명령으로 업데이트합니다. 설정과 키를 새로 입력할 필요는 없습니다.

brew update
brew upgrade --cask skyline-23/departure-board/departure-board

Mac / ZIP: 앱을 완전히 종료한 뒤 새 버전의 앱과 .saver를 모두 교체합니다. Homebrew와 ZIP 설치를 섞어서 같은 앱을 중복 설치하지 마세요.

Windows: 새 버전의 ZIP을 다른 폴더에 풀고 Install.cmd를 실행합니다. 기존 설정과 키는 유지됩니다. 설치 폴더 내부에서 설치 프로그램을 다시 실행하면 오류가 나므로 새 압축 해제 폴더를 사용하세요.

Windows 제거: 앱을 종료하고 설치 폴더의 Uninstall.ps1을 PowerShell에서 실행합니다. 현재 화면 보호기가 Departure Board이면 이전 선택을 복원합니다. 사용자 설정과 API 키는 유지됩니다. 완전히 지우려면 앱을 종료한 뒤 %LOCALAPPDATA%\DepartureBoard와 Credential Manager의 Departure Board 항목을 별도로 정리합니다.

Mac 제거: Homebrew로 설치했다면 brew uninstall --cask skyline-23/departure-board/departure-board를 실행합니다. ZIP 설치라면 응용 프로그램 폴더의 앱과 설치한 화면 보호기를 제거합니다. 일반 제거는 사용자 설정과 키를 유지합니다.

10. 문제가 생겼을 때

증상먼저 확인할 것
설치 안내가 열리지 않음ZIP을 전부 풀었는지, Install Guide.html 옆에 Guide 폴더가 있는지 확인합니다. 설치 후에는 앱의 Install & user guide를 사용합니다
앱 창을 닫았는데 계속 움직임정상입니다. 메뉴 막대 또는 트레이에서 Quit을 선택해야 완전히 종료됩니다
화면 보호기 목록에 없음Mac은 .saver를 설치했는지, Windows는 Install.cmd를 실행했는지 확인합니다. Windows의 Set as screen saver도 사용할 수 있습니다
실제 항공편이 나오지 않음Sample/Live 선택, AeroDataBox 구독, API 키, 인터넷, Last update를 확인합니다
401 / 403 / 429각각 키 인증, 구독·권한, 요청 한도 문제일 수 있습니다. 제공사 계정에서 확인합니다
계속 Loading 또는 No departures조회 완료 여부와 공항별 제공 데이터를 확인합니다. 샘플 모드가 정상인지 먼저 비교합니다
배경화면이 정지함Live wallpaper가 켜져 있고 앱이 실행 중인지 확인합니다. Set as Wallpaper만 누르면 정지 이미지입니다
정지 배경화면이 잘림모니터 구성·배율·작업 표시줄 변경 후 앱에서 정지 배경화면을 다시 적용합니다
Windows 앱이 실행되지 않음x64/ARM64 파일 선택, 전체 압축 해제, 조직 실행 정책을 확인합니다

오류를 제보할 때는 앱 버전, OS 버전, 재현 순서, 화면별 해상도·배율·배치와 API 키가 보이지 않는 사진을 함께 보내세요. 로그 위치와 진단 항목은 진단 안내에 있습니다. 로그를 공개하기 전에 개인 정보가 없는지 확인하세요.

이 설명서와 사진은 앱에 포함되어 인터넷 없이도 열립니다.
